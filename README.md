# CLI Car Game in Rust 🦀

A simple command-line game implemented in Rust using a finite state machine (FSM) approach within a `loop`. 
The project demonstrates basic Rust concepts: ownership, pattern matching (`match`), and standard I/O.

## 🎮 How to Play

The goal is to drive, earn score points, and manage your fuel level.

### Commands:
- **enter** — Get into the car.
- **drive** — Start driving (consumes fuel, earns score).
- **stop** — Stop the car.
- **refuel** — Refill the tank (only possible when stopped and outside the car).
- **exit** — Get out of the car.
- **quit** — Close the game.
